# Case 92: product details (ARIA tabs)

## Feature

Four `role="tab"` buttons in a `tablist` with a roving `tabIndex`: only the selected tab has 0.
Left and Right wrap, Home and End jump, and every move selects at once (automatic activation).
Each `tabpanel` has `aria-labelledby` and `tabIndex={0}`, since it holds no focusable content.
The selected tab is written to the hash with `history.replaceState`.

## What makes it hard

- **Clicks prove nothing about the pattern.** A suite that clicks tabs and reads panels passes a
  tablist with no keyboard support at all.
- **Tab order is about absence.** "Only one tab is a Tab stop" fails only when the test leaves the
  tablist with Shift+Tab or Tab and checks where focus went, or reads every `tabIndex`.
- **Focus and selection are separate states.** Moving focus without selecting looks the same as
  selecting until the test reads `aria-selected` or the panel after the second key.
- **The panel's name comes from the tab.** Without `aria-labelledby` the panel is still visible
  and has the right text; only the accessibility tree shows it is unnamed.

## Approaches

| # | Spec | What it does |
|---|---|---|
| 1 | [`1-keyboard`](1-keyboard.spec.ts) | Walks Tab, Shift+Tab, both arrows across the wrap, Home and End, checking focus, `aria-selected` and the panel each time. |
| 2 | [`2-aria-tree`](2-aria-tree.spec.ts) | Compares an ARIA snapshot of the tablist, finds the panel by its name, and reads every tab's `tabIndex`. |
| 3 | [`3-mouse-and-address`](3-mouse-and-address.spec.ts) | Clicks a tab, checks the URL hash, reloads, and opens a hash directly. |

## Trade-offs

- **1 Keyboard.** The pattern as a keyboard user meets it. It does not check names or the
  address.
- **2 ARIA tree.** Exact about roles, states and names in one assertion. It checks one moment,
  not the keys that lead there.
- **3 Mouse and address.** The only check of deep links and reloads. It never touches the
  keyboard.

A tabs widget is tested with the keyboard, through the accessibility tree, and through the
address bar.
