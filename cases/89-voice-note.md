# 89. Voice note

The Voice note page records a voice note with the microphone.

**Requirements to test:**

- **Record** asks for the microphone. If you block it, the page says how to allow it and does
  not record.
- While recording, the page shows the time so far and a level meter that moves with the sound.
- **Stop** saves the whole recording with its length, and the browser stops using the
  microphone. A recording stops by itself at 0:30.
- Saved voice notes are listed with their length and can be played.
