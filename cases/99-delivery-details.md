# 99. Delivery details

The Delivery details page asks for an address and a delivery option.

**Requirements to test:**

- At 320 CSS pixels wide (a phone, or a desktop window zoomed to 400%) the page never scrolls
  sideways, and every field, option and button is fully on screen (WCAG 1.4.10 Reflow).
- On narrow screens the delivery options are listed one under another instead of in a table.
- Long words, such as the email address, wrap instead of running off the screen.
- Text that the user makes twice as large grows everywhere on the form (WCAG 1.4.4 Resize Text).
- With more space between lines, letters and words (WCAG 1.4.12 Text Spacing), no text is cut
  off.
