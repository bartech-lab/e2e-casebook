# 62. Directory

The Directory page lists 10,000 customers.

**Requirements to test:**

- Only the rows near the visible part of the list exist in the page, so it stays fast.
- Every customer can be reached by scrolling, and by the keyboard: the arrow keys, Page Up, Page
  Down, Home and End. Screen readers hear the position of each row in the whole list.
- The filter ignores upper and lower case and says how many customers match.
- Opening a customer and going back returns to the same place in the list, with focus on that
  customer.
